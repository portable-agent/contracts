# Решение 0001: контракты хранятся отдельно от сервисов

- Статус: принято
- Дата: 2026-08-28

## Решение

OpenAPI, AsyncAPI, JSON Schema и проверяемые примеры хранятся в отдельной репе `contracts`.

## Причина

Сервисы используют разные языки и выпускаются отдельно. Общая схема на границе связывает их слабее, чем
общая библиотека внутренних моделей.

## Последствия

Изменение общей границы проходит отдельное ревью. Каждый сервис сам обновляет свой код и тесты потребителя.
