# Контракты Portable Agent

Эта репа хранит форматы обмена между независимыми сервисами.

## Для чего она нужна

- человек видит API до чтения кода сервиса;
- разные языки используют один формат;
- CI проверяет примеры и схемы;
- несовместимые изменения становятся заметны до выпуска.

Начните с [архитектуры](architecture.md), затем прочитайте [правила разработки](development.md).
Внутренний вызов MCP описан в [MCP Gateway API](mcp-gateway.md).
