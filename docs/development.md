# Разработка

## TDD для контрактов

1. Добавьте пример или тест, который показывает ожидаемый формат.
2. Убедитесь, что проверка падает по понятной причине.
3. Измените схему минимально.
4. Запустите все проверки.
5. Упростите имена и уберите повторения, не меняя поведение.

## Команды

```bash
corepack enable
pnpm install
pnpm lint
pnpm test
pnpm build
pwsh ./scripts/check-docs.ps1
```

## Имена

Используйте короткие и понятные слова: `id`, `type`, `name`, `status`, `result`, `createdAt`.
Сокращение допустимо, только если оно общеизвестно в используемом стандарте, например `id` или `url`.
