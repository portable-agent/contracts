# Архитектура

Репозиторий не запускается как сервис. Его файлы читают разработчики, CI и генераторы документации.

```text
HTTP-клиент  -> openapi/  -> HTTP-сервис
сервис       -> asyncapi/ -> брокер -> другой сервис
виджет       -> schemas/  -> канал пользователя
```

## Источник истины

- HTTP-граница описана в `openapi/`.
- Формат события описан в `asyncapi/` и связанных схемах.
- Пример считается верным только после проверки тестом.

Внутренние Java- и Python-модели не переносятся сюда автоматически. Сначала проектируется стабильная
граница, затем каждый сервис сам отображает её на свои простые модели.
