# Создание встречи

Первое разрешённое действие MVP — `calendar.create_event`. Пока его выполняет `fake-calendar`.
Настоящий провайдер позже использует тот же payload.

## Поля

Обязательны `title`, `startAt`, `endAt` и `timeZone`. `description` и `attendees` можно не передавать.
Время передаётся в ISO 8601 со смещением, а `timeZone` содержит имя IANA, например
`Europe/Moscow`.

JSON Schema проверяет форму данных. Правило `endAt > startAt` проверяет сервис до создания действия.
Если обязательных данных нет, агент должен запросить их и не создавать действие.

## Безопасность

Создание встречи всегда требует явного подтверждения. Подтверждается хеш сохранённого payload:
после показа карточки аргументы нельзя незаметно изменить. Повтор с тем же ключом запроса не должен
создать второе событие.

Action API возвращает сохранённый `payload` вместе с `payloadHash`. Виджет показывает эти данные и
передаёт тот же хеш при подтверждении.

Адреса участников являются персональными данными. Их нельзя писать в обычные логи и тестовые
примеры с настоящими адресами.
