# Диагностика

## Не проходит lint OpenAPI

Запустите `pnpm lint` и исправьте указанный файл. Не отключайте правило только ради зелёной сборки.

## Не проходит тест схемы

Запустите `pnpm test`. Сравните пример со схемой и ожидаемым назначением контракта. Если изменение намеренно
ломает старых клиентов, нужна новая major-версия и инструкция миграции.

## Не строится HTML API

Запустите `pnpm build`. Проверьте ссылки `$ref` и синтаксис YAML.

## Не проходит проверка документации

```powershell
pwsh ./scripts/check-docs.ps1
```

Добавьте отсутствующий файл или раздел. Если структура репозитория изменилась, обновите README и AGENTS.md.
