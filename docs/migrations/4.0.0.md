# Переход на contracts 4.0.0

Версия `4.0.0` добавляет третий вариант `connection` в `MessageResponse.reply` Conversation API и
Channel Gateway API. Для строгих клиентов это breaking change: исчерпывающий `switch` должен уметь
обработать новый тип.

## Что изменить

1. Обновить bundle контрактов до `4.0.0`.
2. Добавить обработку `reply.type == connection`.
3. Проверять `card` по `schemas/connection-widget.schema.json`.
4. Показать `card.button` как обычную HTTPS-ссылку канала.
5. Не сохранять OAuth URL, не извлекать из неё `state` и не отправлять её в логи.

Клиенты, которые пока не умеют показывать кнопку, должны вернуть безопасный текст об обязательном
обновлении. Они не должны трактовать `connection` как подтверждение действия.
