# Переход на 2.0.0

## Что изменилось

`payload` действия `calendar.create_event` больше не является произвольным JSON object. Action API
принимает только поля `title`, `startAt`, `endAt`, `timeZone`, `description` и `attendees` по схеме
`CalendarCreateEventPayload`.

Обязательны `title`, `startAt`, `endAt` и `timeZone`. Неизвестные поля отклоняются с HTTP 400.

## Что сделать клиентам

1. Передавать даты в ISO 8601 со смещением.
2. Передавать IANA time zone, например `Europe/Moscow`, или `UTC`.
3. Удалить из `payload` поля, которых нет в схеме.
4. Обработать HTTP 400 до показа пользователю экрана подтверждения.

Верхнеуровневые поля запроса, endpoint и формат успешного ответа не изменились.
