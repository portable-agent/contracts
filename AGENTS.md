# Правила для AI-агентов

## Назначение

Репозиторий — источник истины для OpenAPI, AsyncAPI и JSON Schema платформы Portable Agent.

## Границы

- Не добавляй сюда код сервиса или общий доменный пакет.
- Не придумывай правила бизнеса по одному примеру.
- Не меняй существующий контракт без проверки совместимости и описания миграции.
- Контракт описывает данные на границе, а не внутренние классы сервиса.

## Структура

- `openapi/` — HTTP API.
- `asyncapi/` — события.
- `schemas/` — общие JSON-форматы.
- `examples/` — проверяемые примеры.
- `test/` — тесты схем и примеров.
- `docs/` — документация репозитория.

## Команды

```bash
corepack enable
pnpm install
pnpm lint
pnpm test
pnpm build
pwsh ./scripts/check-docs.ps1
```

## Правила изменений

1. Сначала добавь или измени тест с ожидаемым примером.
2. Затем внеси минимальное изменение в контракт.
3. Используй простой английский в именах полей: `id`, `name`, `status`, `createdAt`.
4. Не используй сложное слово, если простое точно передаёт смысл.
5. Обнови примеры и документацию в том же pull request.
6. Решение, которое влияет на несколько реп, оформи ADR в `portable-agent/platform`.
7. Не публикуй секреты, личные данные и настоящие реквизиты.
